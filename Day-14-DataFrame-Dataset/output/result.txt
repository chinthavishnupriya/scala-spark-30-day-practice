[info] --- 8. RDD vs DataFrame vs Dataset ---
[info] RDD:
[info] - Low-level distributed collection
[info] - No structured schema by default
[info] - More manual control
[info] - Less optimization compared with structured APIs
[info] DataFrame:
[info] - Distributed table with named columns
[info] - Schema-based
[info] - Catalyst optimizer and Tungsten execution
[info] - Convenient for SQL and analytics
[info] Dataset:
[info] - Strongly typed structured API
[info] - Combines object-oriented programming with Spark SQL
[info] - Compile-time type safety for typed operations
[info] - Uses Spark SQL optimization
[info] --- 9. Key Learning Points ---
[info] 1. DataFrame provides structured tabular data.
[info] 2. Dataset[Employee] provides a strongly typed representation.
[info] 3. Case classes define the schema for typed records.
[info] 4. Dataset can be converted back to a DataFrame using toDF().
[info] 5. Catalyst optimizes Spark SQL and Dataset execution plans.
[info] 6. Typed operations provide compile-time type checking.
[info] 7. Payroll calculations can be performed using Dataset and DataFrame APIs.
