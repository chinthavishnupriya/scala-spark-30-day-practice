# Day 01 - Scala Essentials

## Objective

Practice the core Scala concepts required before working with Apache Spark.

## Topics Covered

1. `val`, `var`, and `lazy val`
2. Immutable collections
3. `for`-comprehension with `yield`
4. `List`, `Vector`, `Set`, and `Map`
5. Traits and multiple implementations
6. Student-grade processing using Scala collections
7. Collection-based filtering and transformation

## Environment

- OS: Ubuntu / WSL
- Scala: 2.12.20
- SBT: 1.10.11
- Java: 17.0.20
