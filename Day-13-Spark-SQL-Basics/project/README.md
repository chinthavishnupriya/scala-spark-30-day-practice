# SBT Project Configuration

Day 13 uses SBT to build and run the Scala Spark application.

## Versions

- SBT: 1.10.11
- Scala: 2.13.18
- Apache Spark: 4.2.0
- Java: OpenJDK 17

The SBT version is configured in:

`project/build.properties`

Generated build directories such as `target/` and `project/target/` are excluded from Git.
