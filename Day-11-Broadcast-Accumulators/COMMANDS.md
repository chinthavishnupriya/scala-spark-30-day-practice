# Day 11 — Commands

## Enter the project

```bash
cd ~/scala-spark-30-day-practice/Day-11-Broadcast-Accumulators
```

## Compile

```bash
sbt compile
```

## Run

```bash
sbt run
```

## Clean build files

```bash
sbt clean
```

## Compile after cleaning

```bash
sbt clean compile
```

## Check Java

```bash
java -version
```

## Check SBT

```bash
sbt --version
```

## Check Scala

```bash
scala -version
```

## View input files

```bash
cat input/products.txt
cat input/transactions.txt
```

## View saved result

```bash
cat output/result.txt
```

git status
