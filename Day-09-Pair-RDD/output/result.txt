--- reduceByKey vs groupByKey ---
reduceByKey:
  Combines values locally before shuffle.
  Usually more efficient for aggregation.
  Sends less data across the network.

groupByKey:
  Groups all values for each key.
  Can move more data across the network.
  Useful when all individual values are required.

--- Pair RDD Concepts ---
Pair RDD:
  An RDD containing key-value pairs such as (key, value).
reduceByKey:
  Aggregates values belonging to the same key.
groupByKey:
  Groups all values belonging to the same key.
mapValues:
  Changes only the values while preserving the keys.
